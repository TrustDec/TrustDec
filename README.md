<h2>How I Work</h2>

<br/>

<p>
  <strong>01 &nbsp; Product first</strong><br/>
  <sub>
    Start with the problem, the user, and the outcome — not the framework.
  </sub>
</p>

<br/>

<p>
  <strong>02 &nbsp; End-to-end ownership</strong><br/>
  <sub>
    Architecture, interface, application, backend, integration, deployment, and iteration.
  </sub>
</p>

<br/>

<p>
  <strong>03 &nbsp; Right tool for the problem</strong><br/>
  <sub>
    Native, cross-platform, web, backend, desktop, or AI — based on what the product actually needs.
  </sub>
</p>

<br/>

<p>
  <strong>04 &nbsp; AI-augmented engineering</strong><br/>
  <sub>
    Use models and agents as part of the engineering system, not as a replacement for engineering judgment.
  </sub>
</p>

<br/>

<p>
  <strong>05 &nbsp; Ship and iterate</strong><br/>
  <sub>
    Working software beats theoretical perfection. Build, learn, refine.
  </sub>
</p>
